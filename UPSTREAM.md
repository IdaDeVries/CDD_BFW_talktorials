# Upstream provenance

This repository contains the the course materials for Computational Drug Discovery (CDD), an elective BSc course at Leiden University. The material is based on selected TeachOpenCADD talktorials.

## Source repositories

Original project:
https://github.com/CDDLeiden/teachopencadd

Course adaptation source:
https://github.com/IdaDeVries/teachopencadd

Current course repository:
https://github.com/IdaDeVries/CDD_BFW_talktorials

## Course-specific modifications

Compared to the upstream TeachOpenCADD project, this repository:

- Is independend of teachopencadd (utils) 
- Uses updated API calls
- Has been restructured for CDD course usage
- Contains only the talktorials used within CDD
- Is tested for use on Noteable AY2627
