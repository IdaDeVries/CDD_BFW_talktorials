# CDD BFW Talktorials

Course materials for Computational Drug Discovery (CDD), an elective BSc course of the Bio-Pharmaceutical Sciences program at Leiden University.

This repository contains a curated selection of TeachOpenCADD talktorials adapted for use within CDD. The material combines theoretical background with practical exercises in cheminformatics and structural bioinformatics focussing on kinases.

The talktorials in this repository have been developed and tested for use on Noteable for the academic year 2026-2027.

## Installation

### Noteable (recommended)

The talktorials in this repository have been developed and tested for use on the Leiden University Noteable platform for Academic Year 2026-2027 (AY2627).

#### Clone the repository using the Noteable interface:
Click **Git** in the top menu bar of Noteable and select **Clone a Repository**.

In the dialog that opens:

1. Paste

   https://github.com/IdaDeVries/CDD_BFW_talktorials.git 

   into **Enter the URL of the remote Git repository**.

2. Ensure **Include submodules** remains checked.

3. Click **Clone**.

Once the repository has been cloned, open the desired talktorial notebook and start working.


#### Clone the repository from the command line:
git clone https://github.com/IdaDeVries/CDD_BFW_talktorials.git
